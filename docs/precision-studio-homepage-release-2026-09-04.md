# Precision Studio 首页发布记录（2026-09-04）

## 发布范围

- 将网站根路径首页切换为已确认的 B 款「Precision Studio」设计。
- 保留商品详情、分类、购物车、账户、新闻和后台现有路由与数据接口。
- 首页商品价格继续从服务端公开商品目录读取，不写死经营价格。
- 首页 News 模块继续从现有新闻数据源读取最新内容。
- 使用原始透明商品图保证车型外观准确，并新增银色影棚与深色测试舱 WebP 场景图。

- 冷银、石墨与安全橙的工业视觉体系。
- XTREME 96V 作为主视觉，XCEED、城市电助力车型和 SMART B02 分层展示。
- 桌面导航与移动端菜单均保留关键购买路径。
- 390px 移动端无横向溢出；购物车与菜单触控区不小于 44px。
- 页面动画仅使用位移与透明度，并支持 `prefers-reduced-motion`。
